# Changelog

## 1.0.0 · initial public release

- Added local Tuya LAN 3.4 control for the EMOS GoSmart P56211 on Sailfish OS.
- Added room and target temperatures, a temperature dial, heating and connection status, thermostat power and physical keypad lock.
- Added firmware operating mode selection for Auto, Temporary, Manual, Boost and Holiday.
- Added command confirmation, timeout feedback and a follow-up read after mode and power changes.
- Added first-run setup, connection verification and a live Sailfish home-screen cover.
- Included English and Czech and packaged the app for aarch64. The tested RPM is build 1.0.0-24.
